# Chip's Challenge - CS-230: A2 Assignment (Java)

A Java recreation of the classic 1989 puzzle game **Chip's Challenge**, developed as part of a university Software Engineering module. The project focuses on object-oriented design and recreates the game's core mechanics using Java and JavaFX.

Players must collect computer chips, solve environmental puzzles, avoid enemies and hazards, and reach the exit before the timer runs out.

## Features

- Recreation of the classic Chip's Challenge gameplay
- Seven playable levels
- Multiple enemy types with unique movement behaviours
- Collectable computer chips and keys
- Locked doors and environmental hazards
- Interactive tiles including buttons, traps, water and ice
- Player profile system
- Persistent high score system
- Level loading from external files

## Technologies

- Java
- JavaFX
- Maven

## Running the Game

Clone or download the repository, then run the `Render.java` class to launch the game.
